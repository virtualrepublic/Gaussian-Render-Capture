## Use it

1. You need the [LDraw parts library](https://library.ldraw.org/) and an LDraw importer for
   Blender (for example *ImportLDraw* or *ldr_tools*).
2. Import `10252_Volkswagen_Beetle.mpd` into an empty Blender scene.
3. Follow the [tutorial](../../docs/TUTORIAL.md) from step 1.

The example of the tutorial used 320 cameras (Subdivisions 3), 3840 × 3840 px renders and the
default export settings. Results:
[Postshot on SuperSplat](https://superspl.at/scene/04caae8c) ·
[LichtFeld Studio in the LichtFeld gallery](https://portal.lichtfeld.io/gallery/s/S5BcEp7xgtTaVIfsgpa2ygW0Pg_zsnMm/)
