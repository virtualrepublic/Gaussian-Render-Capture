## Use it

1. You need the [LDraw parts library](https://library.ldraw.org/) and an LDraw importer for
   Blender (for exam­ple *ImportLDraw* or *ldr_tools*).
2. Import `10252_Volkswagen_Beetle.mpd` into an empty Blender scene.
3. Follow the [tuto­rial](../../docs/TUTORIAL.md) from step 1.

The exam­ple of the tuto­rial used 320 cam­eras (Sub­di­vi­sions 3), 3840 × 3840 px ren­ders and the
default export set­tings. Results:
[Post­shot on SuperSplat](https://superspl.at/scene/04caae8c) ·
[LichtFeld Studio in the LichtFeld gallery](https://portal.lichtfeld.io/gallery/s/S5BcEp7xgtTaVIfsgpa2ygW0Pg_zsnMm/)
